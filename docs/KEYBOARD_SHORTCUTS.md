# ⌨️ Kartu Referensi Tombol Pintas Keyboard Kasir

Gunakan tombol cepat di bawah ini untuk mengoperasikan kasir secepat kilat tanpa perlu menyentuh mouse:

| Tombol | Fungsi Operasi | Keterangan |
| :--- | :--- | :--- |
| **`F2`** | Fokus Pencarian / Scan | Kursor langsung aktif di kotak pencarian produk |
| **`Enter`** *(di pencarian)* | Scan Cepat Barcode | Otomatis menambah produk yang barcode-nya cocok |
| **`F4`** | Tahan Pesanan (*Hold Bill*) | Menyimpan transaksi pelanggan sementara |
| **`F8`** | Buka Riwayat Transaksi | Melihat penjualan sebelumnya & cetak ulang struk |
| **`F9`** | Bayar Pesanan (*Checkout*) | Membuka jendela pembayaran dan kalkulator kembalian |
| **`Escape`** | Tutup Jendela (*Close*) | Menutup pop-up modal struk, pembayaran, atau histori |
| **`Angka 1-4`** *(di pembayaran)* | Ganti Metode Bayar | 1: Tunai, 2: QRIS, 3: Kartu Debit, 4: Transfer |
